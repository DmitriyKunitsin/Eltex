# Лабораторные работы по программированию на C

## Описание
Репозиторий содержит решения 4 лабораторных работ по языку C, демонстрирующих работу с указателями, памятью и строками.

## Содержание

| Файл | Описание |
|------|----------|
| `ex_1.c` | Изменение третьего байта целого числа через указатель |
| `ex_2.c` | Работа с указателями на float (арифметика указателей) |
| `ex_3.c` | Заполнение и вывод массива через арифметику указателей |
| `ex_4.c` | Поиск подстроки в строке с возвратом указателя |

## Подробнее о каждой работе

### Задание 1: Изменение байта числа
**Условие:** Поменять в целом положительном числе значение третьего байта на введённое пользователем число через указатель (без битовых операций).

**Решение:** Через указатель `char*` получаем доступ к побайтовому представлению числа, сдвигаем на 3 байта и изменяем значение.

### Задание 2: Арифметика указателей
**Условие:** Изменить одну строку, чтобы результат сложения через указатели дал `12.0`.

**Исходная ошибка:** `float *xp = &x;` → нужно было прибавить 1 к адресу `x`.

**Исправление:** `float *xp = &x + 1;`

### Задание 3: Массив через указатель
**Условие:** Определить массив из 10 элементов (1..10), заполнить и вывести, используя только арифметику указателей.

**Решение:** В `printArray` заполняется массив от 1 до 10 и выводится через инкремент указателя.

### Задание 4: Поиск подстроки
**Условие:** Найти в введённой строке введённую подстроку, вернуть указатель на начало (или NULL).

**Решение:** Функция `SearchStrk` ищет совпадение посимвольно, возвращает указатель на первое вхождение.
