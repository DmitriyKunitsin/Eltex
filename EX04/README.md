# 📞 Абонентский справочник (Contact Manager)

## 📌 Описание

Консольная программа на C для управления списком контактов.  
Данные хранятся в статическом массиве структур (максимум 100 записей).  
Доступные действия: добавление, удаление, поиск по имени, вывод всех записей, выход.

## 🧱 Структура абонента

struct abonent {
char name[10];
char second_name[10];
char tel[10];
};

## 🎯 Меню программы

1. Добавить абонента
2. Удалить абонента
3. Поиск абонентов по имени
4. Вывод всех записей
5. Выход

## 📂 Файлы проекта

- contact_manager.c — точка входа (main), главный цикл
- contact_manager.h — объявления структуры и функций
- function.c — реализация всех функций

## 🔧 Основные функции

- printMenu() — вывод меню
- selectedMenu() — выбор действия по пункту
- addUser() — добавление абонента в первую свободную запись
- searchIndexNullAbonent() — поиск индекса свободной записи
- printAllUser() — вывод всех непустых абонентов
- searchUser() — поиск абонентов по имени
- removeUser() / deletedUser() — удаление абонента по имени
- inputSting() — безопасный ввод строки (макс. 9 символов)
- my_strlen() — аналог strlen через указатели
- checkValidName() — сравнение имён для поиска/удаления

## ⚠️ Примечания

- Имя, фамилия, телефон — не более 9 символов + \0.
- Для Windows в system("clear") замените на system("cls").
- Поиск и удаление — точное совпадение, регистрозависимо.
- Пустые записи определяются по длине поля name.
