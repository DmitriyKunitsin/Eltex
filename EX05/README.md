# 📞 Абонентский справочник (Contact Manager)

## 📌 Описание

Консольная программа на C для управления списком контактов.  
Данные хранятся в динамическом двусвязном списке (структура `list`).  
Доступные действия: добавление, удаление, поиск по имени, вывод всех записей, выход.

## 🧱 Структуры данных

struct list_abonent {
char *name;
char *second_name;
char *tel;
struct list_abonent *next;
struct list_abonent \*prev;
};

struct list {
int count;
struct list_abonent *head;
struct list_abonent *prev;
};

## 📂 Файлы проекта

- contact_manager.c — точка входа (main), главный цикл
- contact_manager.h — объявления функций
- function.c — реализация функций интерфейса
- struct.c — реализация операций с двусвязным списком
- struct.h — объявления структур и операций списка

## 🔧 Основные функции списка

- db_created() — создание нового списка
- db_insert() — добавление элемента в список
- db_delete() — удаление элемента по индексу
- db_search_name() — поиск индекса по имени
- get_element() — получение элемента по индексу (с оптимизацией выбора направления)
- db_print() — вывод всех записей списка
- db_free() / free_abonent() — рекурсивное освобождение памяти

## 🔧 Основные функции интерфейса

- printMenu() — вывод меню
- selectedMenu() — выбор действия по пункту
- addUser() — добавление абонента (вызов db_insert)
- searchUser() — поиск абонентов по имени (вызов db_search_name)
- removeUser() — удаление абонента по имени
- printAllUser() — вывод всех абонентов (вызов db_print)
- inputSting() — безопасный ввод строки (макс. 9 символов)

## ⚠️ Примечания

- Имя, фамилия, телефон — динамическое выделение памяти (точный размер).
- Для Windows в system("clear") замените на system("cls").
- Поиск и удаление — точное совпадение, регистрозависимо.
- Список двусвязный, элементы хранятся в порядке добавления.
- При удалении память освобождается корректно (рекурсивная очистка).
