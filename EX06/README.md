# 🧮 Консольный калькулятор (Calculator)

## 📌 Описание
Консольная программа на C для выполнения базовых арифметических операций.  
Поддерживает сложение, вычитание, умножение, деление.  
Реализована с модульной структурой (отдельные файлы для каждой операции).

## 🎯 Меню программы
1. Сложение
2. Вычитание
3. Умножение
4. Деление
5. Выход

## 📂 Файлы проекта
- main.c — точка входа (main), главный цикл
- calc.h — объявления всех функций
- add.c — функция сложения
- sub.c — функция вычитания
- mul.c — функция умножения
- div.c — функция деления
- helpers.c — вспомогательные функции (ввод, вывод, меню)

## 🔧 Основные функции
- add() — сложение двух чисел
- sub() — вычитание двух чисел
- mul() — умножение двух чисел
- div() — деление двух чисел
- print_menu() — вывод меню на экран
- input() — ввод числа с проверкой на корректность
- printResult() — вывод результата (целое число без .0, иначе с одним знаком)

## 🛠 Сборка и запуск
gcc main.c add.c sub.c mul.c div.c helpers.c -o calculator
./calculator

## 💡 Пример работы
Выберите операцию:
1) Сложение
2) Вычитание
3) Умножение
4) Деление
5) Выход
Введите номер пункта: 1
Введите 1 число: 10
Введите 2 число: 5
Результат: 15

## ⚠️ Примечания
- Программа проверяет деление на ноль и выводит сообщение об ошибке.
- Ввод чисел защищён от нечисловых значений (повторный запрос).
- Результат выводится без десятичной части, если число целое.
- Для выхода из программы выберите пункт 5.
