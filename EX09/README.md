# 🐧 Работа с процессами в Linux (fork, waitpid, execvp)

## 📌 Описание

Комплект программ на C для изучения работы с процессами в ОС семейства Linux/Unix.  
Демонстрируется создание процессов через `fork()`, ожидание завершения дочерних процессов через `waitpid()`, а также создание простого командного интерпретатора с использованием `execvp()`.

## 📂 Файлы проекта

- ex1.c — создание одного дочернего процесса, вывод PID и PPID, ожидание завершения
- ex2.c — создание иерархии процессов (5 процессов), ожидание завершения всех
- ex3.c — простой командный интерпретатор (shell), выполняющий введённые команды

---

## 1️⃣ Пример 1 (ex1.c)

**Демонстрация:** создание одного дочернего процесса.

- Родительский процесс создаёт дочерний через `fork()`.
- Дочерний процесс выводит свой PID и PPID, затем завершается с кодом 1.
- Родитель ожидает завершения дочернего через `waitpid()` и выводит код завершения.

### 🛠 Сборка и запуск

gcc ex1.c -o ex1
./ex1

### 💡 Пример вывода

Родительский процесс: PID = 1234, PPID = 5678
Дочерний процесс: PID = 1235, PPID = 1234
Дочерний процесс завершился с кодом: 1

---

## 2️⃣ Пример 2 (ex2.c)

**Демонстрация:** создание иерархии из 5 процессов.

- Процесс 1 (первый потомок) создаёт процессы 3 и 4.
- Процесс 2 (второй потомок) создаёт процесс 5.
- Каждый процесс выводит свой PID и PPID.
- Родитель ожидает завершения всех дочерних процессов.

### 🛠 Сборка и запуск

gcc ex2.c -o ex2
./ex2

### 💡 Пример вывода

Процесс 1: PID = 1235, PPID = 1234
Процесс 2: PID = 1236, PPID = 1234
Процесс 3: PID = 1237, PPID = 1235
Процесс 4: PID = 1238, PPID = 1235
Процесс 5: PID = 1239, PPID = 1236

---

## 3️⃣ Пример 3 (ex3.c)

**Демонстрация:** простой командный интерпретатор (shell).

- Бесконечно принимает команды от пользователя.
- Разбивает строку на аргументы (через пробел).
- Создаёт дочерний процесс и вызывает `execvp()` для выполнения команды.
- Поддерживается любая команда из PATH (ls, pwd, echo и т.д.).
- Для выхода введите `exit`.

### 🛠 Сборка и запуск

gcc ex3.c -o ex3
./ex3

### 💡 Пример работы

Добро пожаловать в простой командный интерпретатор!
Введите 'exit' для выхода.

> ls -la
> pwd
> echo Hello World
> exit
> Выход из интерпретатора.

---

## ⚠️ Примечания

- Программы написаны для Linux/Unix-систем (используются заголовочные файлы `unistd.h`, `sys/wait.h`, `sys/types.h`).
- Для компиляции в Windows потребуется WSL или среда типа Cygwin.
- В ex3.c максимальная длина команды — 1024 символа, максимальное количество аргументов — 100.
- Обрабатываются ошибки: неудачное создание процесса, ошибка `execvp()`, некорректный ввод.
