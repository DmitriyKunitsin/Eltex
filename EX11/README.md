# 📡 Межпроцессное взаимодействие (IPC) в Linux

## 📌 Описание

Комплект программ на C для изучения механизмов межпроцессного взаимодействия в ОС семейства Linux/Unix.  
Демонстрируются: неименованные каналы (pipe), именованные каналы (FIFO), конвейеры из нескольких команд (shell с поддержкой |).

## 📂 Файлы проекта

- ex1.c — передача данных между родительским и дочерним процессом через неименованный канал (pipe)
- server.c + client.c — обмен данными через именованный канал (FIFO)
- ex3.c — простой командный интерпретатор с поддержкой конвейера (команды, соединённые знаком |)

---

## 1️⃣ Пример 1 (ex1.c) — неименованный канал (pipe)

**Демонстрация:** передача строки от родительского процесса к дочернему через pipe.

- Родитель создаёт pipe и порождает дочерний процесс.
- Родитель закрывает читающий конец канала, записывает сообщение "Hi!" и закрывает записывающий конец.
- Дочерний процесс закрывает записывающий конец, читает сообщение и выводит его.

### 🛠 Сборка и запуск

gcc ex1.c -o ex1
./ex1

### 💡 Пример вывода

Дочерний процесс прочитал: Hi!

---

## 2️⃣ Пример 2 — именованный канал (FIFO)

**Демонстрация:** обмен данными между двумя независимыми процессами через FIFO.

- Сервер создаёт FIFO в директории `server/`, открывает его на запись и отправляет сообщение "Hi!".
- Клиент открывает тот же FIFO на чтение, читает сообщение и выводит его.

### 🛠 Сборка и запуск

# Создать директорию server/

mkdir server

# Компиляция и запуск сервера

gcc server.c -o server
./server

# Компиляция и запуск клиента (в другом терминале)

gcc client.c -o client
./client

### 💡 Пример вывода (клиент)

Received: Hi!

### ⚠️ Важно

- Сервер и клиент используют относительные пути: `server/my_fifo` и `../server/my_fifo`.
- Для корректной работы оба процесса должны быть запущены, и директория `server/` должна существовать.

---

## 3️⃣ Пример 3 (ex3.c) — командный интерпретатор с поддержкой конвейера

**Демонстрация:** выполнение цепочки команд, соединённых символом `|` (аналог shell pipeline).

- Поддерживается до 10 команд в одном конвейере.
- Используются несколько pipe для соединения процессов.
- Каждая команда запускается в отдельном дочернем процессе.
- Вывод предыдущей команды передаётся на ввод следующей через dup2.

### 🛠 Сборка и запуск

gcc ex3.c -o ex3
./ex3

### 💡 Пример работы

Добро пожаловать в простой командный интерпретатор!
Введите 'exit' для выхода.

> ls -la | grep .c | wc -l
> (вывод количества строк с .c)
> exit
> Выход из интерпретатора.

---

## ⚠️ Примечания

- Программы написаны для Linux/Unix (используются `unistd.h`, `fcntl.h`, `sys/wait.h`, `sys/stat.h`).
- Для Windows потребуется WSL или подобная среда.
- В ex3.c максимальная длина команды — 1024 символа, максимальное число аргументов — 100, максимальное число команд в конвейере — 10.
- Обрабатываются ошибки: создание каналов, fork, dup2, execvp.
