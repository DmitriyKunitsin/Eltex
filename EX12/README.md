# 💬 Мессенджер на POSIX очередях сообщений (Chat via mqueue)

## 📌 Описание

Распределённый чат на C с использованием **POSIX очередей сообщений** (`mqueue`) и **ncurses** для интерфейса.  
Проект демонстрирует:

- Регистрацию клиентов на сервере
- Обмен сообщениями между клиентами через сервер
- Асинхронный ввод/вывод через очереди
- Работу с динамическими структурами данных
- Многопоточность на сервере

## 🧱 Структуры данных

struct User {
int id; // уникальный ID пользователя
char user_name[50]; // имя пользователя
char queue_name[50]; // имя очереди для сообщений
bool is_active; // статус активности
};

struct User_Registry {
User \*users; // динамический массив пользователей
size_t count; // текущее количество
size_t capacity; // вместимость
mqd_t mq_server; // дескриптор серверной очереди
};

## 🎯 Функционал

- Регистрация нового клиента (имя)
- Присвоение ID и уникальной очереди
- Отправка и получение сообщений через сервер
- Отображение списка онлайн-пользователей
- Выход с корректной очисткой ресурсов

## 📂 Файлы проекта

- server.c — точка входа сервера, управление очередью и пользователями
- server.h — объявления серверных функций
- client.c — клиентский интерфейс (ncurses), отправка/приём сообщений
- client.h — объявления клиентских функций
- front.h — работа с окнами ncurses
- util.h — общие структуры и макросы

## 🔧 Основные функции

| Функция                  | Назначение                                    |
| ------------------------ | --------------------------------------------- |
| `init_user_registry()`   | инициализация реестра пользователей           |
| `add_user()`             | добавление пользователя в реестр              |
| `exit_user()`            | деактивация пользователя (пометка неактивным) |
| `find_user()`            | поиск пользователя по ID и имени              |
| `create_client_queue()`  | создание очереди для клиента                  |
| `chat_function()`        | потоковая обработка сообщений на сервере      |
| `registration_message()` | регистрация на клиенте                        |
| `init_windows()`         | инициализация ncurses окон                    |

## 🛠 Сборка и запуск

### Компиляция (требуется линковка с librt и pthread)

gcc -o server server.c -lrt -lpthread
gcc -o client client.c -lrt -lpthread -lncurses

### Запуск

# Терминал 1

./server

# Терминал 2

./client

## ⚠️ Примечания

- Очереди сообщений POSIX создаются в `/dev/mqueue` (требуются права).
- Для работы ncurses нужна библиотека `libncurses-dev`.
- При завершении клиента отправляется `exit:` для корректной деактивации.
- Поддерживается до 1024 сообщений в очереди, размер сообщения — 256 байт.
